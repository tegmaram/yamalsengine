# Yamalsengine — The Relay

A small first-person storm maze for 64-bit Windows, rendered in Vulkan 1.3.
[Four seconds of engine footage](shots/rain.mp4): the first second is unlit, then the flashlight switches on and the camera walks into the rain. Captured offline via the same Vulkan renderer, maze generator and player controller; not a real-time benchmark.

## Play / build

Unzip the portable game and run `horror.exe` **with its shaders folder alongside it**. No compiler, SDK, installer or admin permissions needed to play. Requires a Windows Vulkan graphics driver supporting 1.3 dynamic rendering.

For the small source build: unpack **Zig 0.13.0** (the single C++ compiler/linker toolchain), then:

```powershell
.\build.ps1 -Zig C:\tools\zig\zig.exe -Run
```

This path needs **no Visual Studio, CMake, Ninja, full Vulkan SDK or GLSL compiler**. Setup downloads checksum-pinned Vulkan *headers* to `build/deps` on first use. To build offline, pass `-Headers C:\path\to\Vulkan-Headers\include`. Existing `VULKAN_SDK` headers are also recognized. The executable and six shipped SPIR-V modules are under `build/portable`. Copy only `horror.exe` and `shaders/` to distribute. Zig caches compilation; cold and incremental times differ significantly.

Already have MSVC and Vulkan SDK? Use a developer shell: `cmake --preset release` then `cmake --build --preset release`. This alternate path recompiles GLSL with `glslc`. After shader edits, refresh `shaders/compiled/*.spv` and the source/binary SHA256 manifest before distributing the portable build.

## Game

Find the orange relay using the stereo pulse. Its direction follows **the next open passage**, not a straight line through walls. Press **E** near it to activate it. The relay falls silent and the storm builds: return to your starting cell. The window title reports progress. Use `--hints` for visual direction cues and `--reduced-flash` to disable lightning flashes.

WASD to move, mouse to look, Shift to sprint, C/Ctrl to crouch, F for flashlight, hold R to force a storm, F1 to release/capture the mouse, Esc to quit.

## Rendering and measurement

- Depth-tested falling drops are generated by one instanced draw, scaled by rainfall, skipped in dry weather. No per-drop CPU update. Flashlight intensity depends on each drop's position inside the cone.
- Sustained rainfall accumulates surface water; a fixed ground-height approximation yields growing puddle outlines. Rain adds impact rings, highlights and a grazing sky sheen. Pools drain as weather clears; this is not fluid dynamics or scene reflection tracing.
- Flashlight shadows use up to eight nearby solid boxes rather than an extra shadow pass. The approximation deliberately omits distant blockers. Clouds use a baked 2D mipmapped sheet.
- Player collisions run at 60 Hz; render position interpolates between steps, while mouse look stays immediate.
- Benchmark clear and storm separately, on the same device and seed. For example `horror.exe --bench --frames 1200 --fps 0 --seed 42 --storm 1 --light 1`. Reports median/p95/p99 frame intervals and, where supported, GPU timestamp durations after warmup. Uncapped disables the CPU limiter, not the presentation system. No guaranteed FPS across hardware.
- Regression capture: `horror.exe --frames 60 --seed 42 --shot storm.bmp --storm 1 --light 1`. Capture uses a fixed time step.

## Developer checks

`g++ -std=c++17 -O2 -Isrc tests/core.cpp src/maze.cpp src/player.cpp -o core-test` builds the standalone CPU tests (no Vulkan). They check 1,000 seeds, routing, crouch clearance and standing recovery. CI also builds the portable Windows target.

On Linux with Vulkan headers, a loader and a Vulkan 1.3 driver exposing `VK_EXT_headless_surface`, reproduce the silent camera take without a window system:

```sh
c++ -std=c++17 -O2 -DNDEBUG -Isrc tools/rain_capture.cpp src/{maze,player,vk_engine,cloudtex}.cpp -lvulkan -o /tmp/rain-capture
mkdir -p /tmp/rain-frames
/tmp/rain-capture shaders/compiled /tmp/rain-frames
ffmpeg -framerate 24 -i /tmp/rain-frames/%03d.bmp -c:v libx264 -crf 17 -pix_fmt yuv420p -movflags +faststart rain.mp4
```
